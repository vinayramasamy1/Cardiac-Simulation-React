# System Usability Scale (SUS)

## What it is and why use it

SUS is a free, 10-question survey that has been used for decades. It produces one score from 0-100. It's useful because it's **standard**, so you can compare your score to published benchmarks and to your own score after you make fixes.

## Instructions to read to the participant

"For each statement, circle how much you agree, from 1 (Strongly Disagree) to 5 (Strongly Agree). Answer based on your gut reaction. Don't think too long."

## Questions

Participant ID: ________

| # | Statement | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | I think that I would like to use this website frequently. | | | | | |
| 2 | I found the website unnecessarily complex. | | | | | |
| 3 | I thought the website was easy to use. | | | | | |
| 4 | I think that I would need the support of a technical person to be able to use this website. | | | | | |
| 5 | I found the various functions in this website were well integrated. | | | | | |
| 6 | I thought there was too much inconsistency in this website. | | | | | |
| 7 | I would imagine that most people would learn to use this website very quickly. | | | | | |
| 8 | I found the website very cumbersome to use. | | | | | |
| 9 | I felt very confident using the website. | | | | | |
| 10 | I needed to learn a lot of things before I could get going with this website. | | | | | |

*Do not reword the questions.* Changing the wording breaks comparability with the published benchmarks.

## How to score

1. **Odd questions (1, 3, 5, 7, 9):** score = answer - 1
2. **Even questions (2, 4, 6, 8, 10):** score = 5 - answer
3. Add all 10 scores (range 0-40).
4. **Multiply by 2.5.** That is the SUS score (0-100).
5. Average across participants.

*Why odd and even are scored differently:* The survey alternates positive and negative statements to catch people who just circle all 4s without reading.

## Interpreting the score

| SUS | Meaning |
| --- | --- |
| Below 50 | Poor, serious problems |
| 50-68 | Below average, needs work |
| **68** | **Industry average** |
| 68-80 | Good |
| 80+ | Excellent |

With only 5-8 participants, treat SUS as a rough indicator. Its main value is comparing round 1 to round 2 after fixes.
